# ZenFi Tech — integração inicial com WhatsApp Cloud API

## Arquivos
- `servidor_zenfi_whatsapp.py`: servidor Python atualizado, com webhook, vínculo por código e fila de lançamentos.
- `zenfi_whatsapp.html`: aplicativo original com sincronização da fila do WhatsApp.
- O servidor procura `zenfi_whatsapp.html` na mesma pasta.

## Como funciona
1. O usuário entra no ZenFi e abre Configurações > Conectar WhatsApp.
2. Informa o número com DDI, por exemplo `+55 11 99999-9999`.
3. O servidor solicita à Meta o envio de um template aprovado com código de verificação.
4. Depois de vinculado, o usuário envia mensagens de texto ao número oficial da empresa.
5. Mensagens como `Gastei R$ 35 no almoço` ou `Recebi R$ 2.500 de salário` são interpretadas.
6. O webhook guarda a movimentação e o app a importa quando estiver aberto e autenticado.

## Variáveis de ambiente necessárias
Configure no serviço de hospedagem:
- `META_VERIFY_TOKEN`: segredo aleatório escolhido por você, usado no campo “Verificar token” da Meta.
- `META_APP_SECRET`: segredo do aplicativo (App Secret) do painel Meta, usado para validar a assinatura dos webhooks.
- `WHATSAPP_TOKEN`: token de acesso da WhatsApp Cloud API (mantenha secreto).
- `WHATSAPP_PHONE_NUMBER_ID`: ID do número de telefone exibido no painel Meta.
- `WHATSAPP_VERIFY_TEMPLATE`: nome do template de autenticação aprovado, padrão `zenfi_verificacao`.
- `WHATSAPP_API_VERSION`: opcional; padrão `v23.0`.

**Importante:** crie e aprove na Meta um template de autenticação chamado `zenfi_verificacao`, em português (`pt_BR`), com um parâmetro de texto no corpo para o código. O envio do código não funcionará até existir um template compatível e as credenciais reais estarem configuradas.

## Configuração do webhook na Meta
- URL de callback: `https://SEU-DOMINIO/webhook/whatsapp`
- Verificar token: o mesmo valor de `META_VERIFY_TOKEN`.
- Assine o campo `messages` no webhook da conta WhatsApp Business.

## Executar para teste local
```bash
python servidor_zenfi_whatsapp.py
```
O servidor local não é acessível pela Meta. Para validar webhook real, hospede o Python em serviço HTTPS público.

## Limitações importantes
- O aplicativo original usa armazenamento local no navegador quando não há banco de dados em nuvem ativo. A fila do WhatsApp fica salva no servidor e é importada na próxima vez que o usuário abrir o app e estiver conectado. Para atualização imediata mesmo com o navegador fechado, é necessário conectar o armazenamento financeiro do app a um banco de dados em nuvem.
- A classificação de texto é simples e baseada em palavras-chave. Mensagens ambíguas, áudios, imagens, comprovantes e mensagens sem valor explícito não são lançados.
- Antes de produção, configure HTTPS, variáveis secretas, backup do SQLite ou banco gerenciado, política de privacidade e testes com número de teste da Meta.
- Este pacote não contém nem inventa tokens, IDs da Meta ou domínio de hospedagem.


## Publicação no Render (GitHub + Web Service)
1. Coloque estes arquivos na raiz de um repositório GitHub: `servidor_zenfi_whatsapp.py`, `zenfi_whatsapp.html`, `requirements.txt` e `Procfile`.
2. No Render, escolha New > Web Service e conecte esse repositório.
3. Runtime: Python; Build Command: `pip install -r requirements.txt`; Start Command: `python servidor_zenfi_whatsapp.py`.
4. Configure as variáveis de ambiente listadas acima.
5. Adicione um disco persistente (Persistent Disk) montado em `/var/data` e ajuste `ARQ_BANCO` para `/var/data/zenfi.db` antes de produção. Sem disco persistente, o SQLite pode ser apagado em novos deploys/reinícios.
6. Após o deploy, teste a página e depois configure o webhook em `https://SEU-SERVICO.onrender.com/webhook/whatsapp`.

Aviso: o código ainda precisa de revisão de segurança antes de receber tráfego real (incluindo validação da assinatura X-Hub-Signature-256 dos webhooks, proteção contra abuso e política de retenção). Não use dados reais de clientes até concluir essa etapa.
